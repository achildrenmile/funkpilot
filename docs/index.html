Setup

In 3 Minuten starten

Docker oder Node.js — deine Wahl.

terminal 
# Repository klonen
git clone https://github.com/achildrenmile/funkpilot.git
cd funkpilot

# Option A: Docker (empfohlen)
docker compose up -d

# Option B: Node.js
npm install
npm run dev

# → http://localhost:5173
